---

## Rules
- **Semantics**: Use `<button>` for actions, `<a>` for navigation. No clickable `<div>`s.
- **Alt Text**: All images must have meaningful `alt` text.
- **Focus States**: Use `focus-visible:ring` for keyboard focus visibility.
- **Motion**: Respect `prefers-reduced-motion` in all custom CSS animations.
