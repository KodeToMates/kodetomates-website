## Rules
- **Tokens**: Use `--color-primary`, `--color-secondary`, `--color-background`, etc.
- **Tailwind v4**: Map classes directly to CSS variables defined in `@theme` of `globals.css`.
- **No arbitrary values**: Do not use `w-[15px]` or `bg-[#f00]` unless strictly necessary and documented.
